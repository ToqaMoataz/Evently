# Evently – Flutter App

**Evently** is a Flutter-based Todo & Event Management application that allows users to create, manage, and organize events efficiently. The app supports multiple languages and provides a responsive UI with dark and light themes.

## Features

- **User Authentication:** Users can sign up, log in, and log out using Firebase Authentication.  
- **User Profiles:** User images are stored and managed via Cloudinary.  
- **Event Management:** Users can create, update, delete, and view event details. Event info is stored in Firebase's Firestore.  
- **Google Maps Integration:** Set the location for each event directly on the map.  
- **Multi-language Support:** Arabic and English languages supported.  
- **Themes:** Dark and light themes available.  
- **Responsive UI:** Adaptive layouts using Screen Utils for different screen sizes.  
- **Architecture & State Management:** Follows Clean Architecture with MVVM; uses Cubit and Provider for state management.  

## Technologies & Tools

- Flutter  
- Firebase (Authentication & Firestore)  
- Cloudinary (for user images)  
- Google Maps API  
- Provider & Cubit (State Management)  
- MVVM & Clean Architecture  
- Screen Utils (Responsive UI)
